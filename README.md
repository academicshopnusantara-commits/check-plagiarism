# 📄 Plagiarism Checker Web App

Website sederhana untuk cek plagiasi dokumen dengan sistem user & admin.

## 🚀 Fitur

### 👤 User
- Upload dokumen
- Download hasil plagiasi
- Redeem code
- Edit profil
- Beli paket & upload pembayaran

### 🛠️ Admin
- Download dokumen user
- Upload hasil plagiasi
- Generate redeem code
- Kelola user
- Buat pengumuman

---

## 🧱 Tech Stack

- Frontend: React.js
- Backend: Node.js + Express
- Database: MongoDB
